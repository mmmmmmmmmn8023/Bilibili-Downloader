下载设置

可用变量：
uid UID   UpName UP主   bvid BV号(图文为空)
dynType 类型   dynamicId 动态ID
pubdate 日期   pubtime 时间   qn 画质(图文为空)

语法：
变量名 直接替换   (:变量 默认值) 空时用默认   / 子文件夹

示例：
dynType → 按类型分目录(投稿视频/图文/…)   pubdate/UpName-bvid → 日期/UP主-BV号
可用变量：
avTitle 标题   UpName UP主   uid UID
bvid BV号(图文为空)   dynType 类型   dynamicId 动态ID
pubdate 日期   pubtime 时间   qn 画质(图文为空)

语法：
变量名 直接替换   (:变量 默认值) 空时用默认   ⚠️ 不可用 / 分文件夹

示例：
avTitle-UpName → 标题-UP主   bvid-pubdate → BV号-日期   dynamicId → 动态ID
